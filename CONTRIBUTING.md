# Contributing to Sigil

Thank you for your interest in Sigil! We welcome contributions to the language and its tooling.

## Licensing Agreement

By contributing to this repository, you agree that your contributions will be licensed under the project's existing licenses:

- **CC BY 4.0** for documentation and specifications.
- **Apache 2.0** for code and software implementations.

## How to Participate

1. **RFCs (Request for Comments):** For changes to the Sigil syntax or grammar, please open an Issue labeled `RFC` to discuss the logic before submitting a Pull Request.
2. **Bug Reports:** If you find an edge case where the grammar fails, please provide a minimal Sigil code example that reproduces the error.
3. **Pull Requests:** Ensure your PR includes updated documentation if you are changing how a Sigil feature works.

For direct inquiries, contact Curtis DeGidio at curtis.degidio@gmail.com.
